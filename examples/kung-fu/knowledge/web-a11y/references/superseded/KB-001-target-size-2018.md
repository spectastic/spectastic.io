# WCAG 2.1 target size (prior edition, retained)

Under **WCAG 2.1** (W3C Recommendation, **5 June 2018**) the only target-size success criterion was
**SC 2.5.5 Target Size (Enhanced)** at **Level AAA**, requiring **44×44 CSS pixels**. WCAG 2.1 had
**no Level-AA minimum-target-size criterion** at all — the AA floor arrived later, as **SC 2.5.8
Target Size (Minimum)** in WCAG 2.2 (2023).

This edition is retained so that an edition-pinned citation `KB-001@2018-06-05` still resolves to the
text it grounded against, rather than dangling.
