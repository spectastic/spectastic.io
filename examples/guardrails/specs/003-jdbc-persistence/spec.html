1 · Context

The in-memory repository does not survive a restart. This feature implements the persistence port with JDBC. Because real SQL now exists, ADR-0007 gains a content rule (Semgrep) and an operational DB grant alongside its ArchUnit boundary rule — the second sighting of the decision, and a routine one.

2 · User scenarios & testing

Durable. A booked trade is read back after a restart.

Still the single writer. The JDBC adapter is the only code that writes the positions table.

3 · Requirements

The persistence port MUST be implemented by a JDBC adapter that durably stores positions. The JDBC adapter MUST remain the single writer of the positions table and the single emitter of PositionChanged (ADR-0007). The domain MUST NOT import the JDBC library — persistence stays behind the port.
  • Connection-pool tuning — an ops concern.
  • A read API over positions — the next feature.

4 · Data model

positions table
instrument, quantity — written only by the adapter, guarded by ADR-0007.
