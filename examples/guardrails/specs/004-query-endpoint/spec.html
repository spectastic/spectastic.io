1 · Context

Downstream tools want to read a current position over HTTP. This endpoint is read-only; it does not mutate positions and does not touch ADR-0007. Its role in this example is distance — a merge that never mentions the decision.

2 · User scenarios & testing

Read a position. A GET returns the current quantity for an instrument.

Missing instrument. An unknown instrument returns 404.

3 · Requirements

The endpoint MUST return the current quantity for a known instrument. The endpoint MUST be read-only — it MUST NOT mutate any position. The endpoint SHOULD read through the existing adapter, not a new data path.
  • A history/time-series API — a later analytics feature.
  • Authentication — handled by the gateway.

4 · Data model

Position view
instrument + quantity, read-only projection.

5 · Success criteria

A GET returns the current quantity and no request path mutates a position.
Observed at

An HTTP test asserting the read result and the absence of any write.
