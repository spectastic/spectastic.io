14 tasks across four phases. Setup (the Gradle bootstrap every later feature reuses) → Foundational (the core records and the port) → User stories (US1 booking · US2 the JDK-only rule) → Polish. 1 · Execution strategy

Setup → Foundational → US1 → US2 → Polish. The build must be green at the end of Setup before any Java is written; each story closes its conformance before the next opens. This is the tab in use — solo work on a build that has never compiled before, where the bootstrap is the risk.

Setup → Foundational → US1 only; SC-002's ArchUnit rule follows once booking is green.

Not applicable — one engineer, one package.

2 · Phase 1 — Setup

The Gradle bootstrap (design D-001, D-004). Nothing in this repository has compiled before; every later feature builds on these files.

Bootstrap the Gradle build — settings.gradle (rootProject.name = 'position-keeper'), build.gradle in the Groovy DSL with the java plugin, java.toolchain.languageVersion = 21, version = '0.1.0', Maven Central, junit-bom:5.11.4 + junit-jupiter + junit-platform-launcher, archunit:1.4.1, test { useJUnitPlatform() }, and the Spotless 8.10.2 (google-java-format 1.36.1, targeting the two Gradle source sets only) and Checkstyle 14.1.0 plugin blocks; commit the 9.2.1 wrapper via gradle wrapper --gradle-version 9.2.1. build.gradle
Write the minimal Checkstyle config — a Checker with TreeWalker holding UnusedImports, RedundantImport, AvoidStarImport and OuterTypeFilename; no line-length rule (google-java-format owns layout). config/checkstyle/checkstyle.xml
Add the Gradle ignores — run spectastic gitignore --stack now that build.gradle exists (it merges build/ target/ *.class into the managed block), then add .gradle/ and *.mv.db by hand outside the managed block. .gitignore
Fill the Setup / build / test commands — replace the four placeholders with ./gradlew build, ./gradlew test, ./gradlew spotlessApply checkstyleMain checkstyleTest and the install line (./gradlew provisions its own Gradle; any JDK 17+ host runs it, the toolchain provisions 21). AGENTS.md
Install the CI gate — spectastic init --tools --ci github writes the managed spectastic.yml (validate → enforce → merge verdict on every pull request; pinned to the installing CLI); beside it a project-owned build.yml runs ./gradlew build on push and pull request with actions/setup-java Temurin 21. .github/workflows/

3 · Phase 2 — Foundational

The core package no story can ship without (design D-002). JDK-only, per NFR-001.

Define the core records — record Position(String instrument, long quantity) and record TradeEvent(String tradeId, String instrument, long quantity), each rejecting a null or blank instrument/tradeId in its compact constructor. src/main/java/xyz/briancorbin/pk/hex/core/
Declare the repository port — Optional<Position> find(String instrument), boolean wasApplied(String tradeId), void write(String instrument, long quantity, String tradeId); the write records the tradeId with the quantity (design D-005). src/main/java/xyz/briancorbin/pk/hex/core/PositionRepository.java

4 · Phase 3a — US1 · A trade updates a position, idempotent on tradeId

Tests (write & fail first)

Test booking and re-booking — book BUY 100 AAPL (tradeId t-1) and assert the repository's position reads 100; book the same event again and assert it still reads 100 and wasApplied("t-1") is true; book a second tradeId for −40 and assert 60. Fails to compile until T-110/T-111 exist. src/test/java/xyz/briancorbin/pk/hex/app/PositionServiceTest.java

Implementation

Implement the booking use case — PositionService(PositionRepository) with Position book(TradeEvent): return the current position unchanged when wasApplied(tradeId); otherwise add the quantity to find(instrument) (zero when absent) and write the new quantity with the tradeId; expose Position current(String instrument). src/main/java/xyz/briancorbin/pk/hex/app/PositionService.java
Implement the in-memory adapter — a HashMap<String, Long> of quantities and a HashSet<String> of applied tradeIds; write updates both. src/main/java/xyz/briancorbin/pk/hex/persistence/InMemoryPositionRepository.java
Exercise the booking path — run ./gradlew test --tests 'xyz.briancorbin.pk.hex.app.PositionServiceTest' and confirm the three assertions from T-100 pass against the assembled core; this is the library's entry point until 004 adds an HTTP one.

Closes FR-001, FR-002, FR-003, SC-001.
