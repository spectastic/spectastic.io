1 · Context

The system needs instrument static data (name, currency, lot size). This feature loads it from a reference feed into its own store. It has nothing to do with positions and does not touch ADR-0007 — distance in the timeline.

2 · User scenarios & testing

Lookup. An instrument returns its static attributes.

Refresh. A new reference feed updates the static data.

3 · Requirements

The system MUST load instrument static data from the reference feed into a reference store. A lookup MUST return an instrument’s name, currency, and lot size. Reference data SHOULD live in its own module, separate from positions.
  • Point-in-time reference versioning — a later feature.
  • Corporate-action handling — out of scope here.

4 · Data model

Instrument
symbol, name, currency, lot size — static reference attributes.

5 · Success criteria

After a feed load, an instrument lookup returns its name, currency, and lot size.
Observed at

A test loading a fixture feed and asserting the lookup.
