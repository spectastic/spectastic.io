3 · Phase 3a — US1 · Lookup after a feed load, and refresh

Tests (write & fail first)

Test load, lookup and refresh — load a fixture feed from a StringReader and assert lookup("AAPL") returns name, currency and lot size; assert an unknown symbol is empty; load a second feed that renames AAPL and drops MSFT and assert the store reflects exactly the new feed; assert the bundled refdata/instruments.csv loads from the classpath with at least one row; assert a row with three columns throws naming its line. src/test/java/xyz/briancorbin/pk/refdata/ReferenceStoreTest.java
Assert the module boundary both ways — two methods in CoreRulesTest: no class in ..refdata.. depends on ..hex.., and no class in ..hex.. depends on ..refdata.. (design D-001; spec NFR-001). src/test/java/xyz/briancorbin/pk/enforcement/CoreRulesTest.java

Implementation

Implement the feed loader — List<Instrument> load(Reader): read the header, require the four column names in order, split each line on commas, parse lotSize; throw IllegalArgumentException("line N: …") on a malformed row; loadBundled() reads /refdata/instruments.csv from the classpath. src/main/java/xyz/briancorbin/pk/refdata/ReferenceFeedLoader.java
Implement the store — void load(List<Instrument>) replaces the map wholesale; Optional<Instrument> lookup(String symbol); int size(). src/main/java/xyz/briancorbin/pk/refdata/ReferenceStore.java
Load the bundled feed at start and exercise it — Main builds a ReferenceStore from loadBundled() and logs the count; run ./gradlew test --tests '*ReferenceStoreTest' --tests '*CoreRulesTest' green, then ./gradlew run and confirm the start-up line reports the instruments loaded. src/main/java/xyz/briancorbin/pk/Main.java
